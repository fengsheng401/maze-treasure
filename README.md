# 遗迹寻钥 · 源码说明

## 目录长这样

```
src/                     ← 改代码改这里
  index.html               页面结构（312 行）+ 内嵌音乐数据
  style.css                全部样式（1,134 行）
  game.js                  全部游戏逻辑（1,003 行）
  audio.js                 背景音乐播放 + 离线安装（69 行）
build.py                 ← 合并脚本，把上面四个拼回单文件
迷宫寻宝.html             ← 生成物，发给别人、双击玩都用这个
备份/                    ← 历史版本，不用管
```

**规则一句话：永远只改 `src/` 里的文件，`迷宫寻宝.html` 不要手改。**
因为它每次都是被 `build.py` 覆盖生成的，手改的内容会丢。

## 平时怎么用

**看效果**：直接双击 `src/index.html`，浏览器就能跑，改完按 F5 刷新。

**发布给别人**：在本目录开命令行，运行

```
D:\python\python.exe build.py
```

它会重新生成 `迷宫寻宝.html`，这个才是可以拷给别人的单文件。

## 两个注意事项

**1. 音乐数据在 `src/index.html` 里**

那 2.77 MB 的 base64 是背景音乐，占了 `index.html` 绝大部分体积。改页面结构时它不会碍事，但文件大，编辑器打开会慢一点。

**2. `game.js` 里 9 个模块锚点顺序是乱的**

```
第  66 行  [05] 存档与设置
第 229 行  [06] 每日挑战
第 318 行  [12] 关卡编辑器
第 401 行  [07] 地图生成
第 481 行  [13] 点击格子自动行走
第 612 行  [08] 视野与光照
第 657 行  [09] 单格类型
第 735 行  [10] 渲染
第 839 行  [11] 交互流程
```

编号不是按行号递增的（`[12]` 排在 `[07]` 前面），因为编辑器那块是后来插进去的。**按搜索定位，不要按编号顺序找。**
