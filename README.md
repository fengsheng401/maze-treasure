# 遗迹寻钥 · 源码说明

## 目录长这样

```
src/                     ← 改代码只改这里
  index.html               页面结构（312 行）+ 内嵌音乐数据
  style.css                全部样式（1,134 行）
  01-core.js               常量表、全局状态、引导与回放（65 行）
  02-save.js               存档、设置、每日挑战、关卡编辑器（252 行）
  03-map.js                地图生成、点击自动走、视野光照（339 行）
  04-render.js             单格类型判定、画面绘制（182 行）
  05-play.js               交互流程 + 全部事件绑定与启动（166 行）
  audio.js                 背景音乐播放 + 离线安装（69 行）

build.py                 ← 合并脚本，把上面八个拼回单文件（带自检）
README.md                ← 就是本文件
.gitignore / .gitattributes
迷宫寻宝.html             ← 生成物，发给别人、双击玩都用这个
备份/                    ← 历史版本，不用管
```

**两条纪律：**

1. **永远只改 `src/` 里的文件**，`迷宫寻宝.html` 是生成物，手改会被覆盖。
2. **`src/` 里那几个 `.js` 的加载顺序不能调换**（`01` → `02` → `03` → `04` → `05` → `audio`），换了会报“未定义”。

## 平时怎么用

**看效果**：双击 `src/index.html`，浏览器直接能跑，改完按 F5。

**发布给别人**：本目录开命令行，运行

```
D:\python\python.exe build.py
```

成功后它会打印大小和脚本顺序。如果哪个文件坏了或音乐丢了，**它会报错并且不覆盖产物**——不会让你拿到一个半成品。

## 关于版本控制

已经初始化 git，第一次提交是 `bd420da`。

改完一段代码想存个档：

```
git add -A
git commit -m "改了什么"
```

想看历史：

```
git log --oneline
```

**回滚到某次提交**（会丢掉之后的修改，慎用）：

```
git checkout bd420da -- src/
```

`迷宫寻宝.html`（生成物）、`备份/`、截图都被 `.gitignore` 排除了，不会进仓库。

## 一个注意事项

`src/index.html` 有 2.79 MB，其中 2.77 MB 是背景音乐的 base64。这个文件改结构时才会动，平时改逻辑不会碰它，所以 git 不会每次都多存 2 MB。
